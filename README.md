## 📌 Tasks Overview

| Task | Title | Description | Tech Stack |
|---|---|---|---|
| 1 | [Web Data Collection & Analysis](./Task1_Web_Data_Collection) | Scraped public web data, cleaned it, ran EDA, and visualized insights | Python, BeautifulSoup, Pandas, Matplotlib, Seaborn |
| 2 | [Exploratory Data Analysis](./Task2_EDA) | In-depth EDA on the Spotify Tracks Dataset — data cleaning, univariate/bivariate/categorical analysis, genre "fingerprints," and a hit-vs-non-hit comparison | Python, Pandas, NumPy, Matplotlib, Seaborn |
| 3 | [Data Visualization](./Task3_Visualization) | A full set of 14 designed visualizations plus a summary dashboard on the Spotify Tracks Dataset | Python, Pandas, Matplotlib, Seaborn, Plotly |
| 4 | [Sentiment Analysis](./Task4_Sentiment_Analysis) | NLP-based sentiment classification of Amazon product reviews using VADER, with WordClouds and word-frequency analysis | Python, NLTK, VADER, WordCloud, Pandas |

## 🛠️ General Tech Stack

Across the internship, the following tools and libraries were used:

- **Python** – core programming language
- **Pandas / NumPy** – data manipulation and analysis
- **Matplotlib / Seaborn / Plotly** – data visualization (static and interactive)
- **BeautifulSoup / Requests** – web scraping
- **NLTK / VADER / WordCloud** – natural language processing and sentiment analysis
- **Jupyter Notebook / Google Colab** – exploratory work
- **Git & GitHub** – version control

## 🎯 Skills Gained

  type conversion)
- Exploratory Data Analysis (EDA) and statistical summarization
- Building clear, insight-driven visualizations and dashboards
- Natural language processing and lexicon-based sentiment analysis
- Organizing reproducible, well-documented data projects
- Version control and collaborative workflows with Git/GitHub
